<a id="pin"></a>

## 3. Introducir o comprobar el PIN

1. Más → **Host Mode**.
2. La primera vez: escribe un PIN de **al menos 4 dígitos**, repítelo y **Crear PIN y entrar**.
3. Las siguientes: escribe el PIN y **Entrar**. Si falla: “PIN incorrecto. Inténtalo otra vez.”
4. Para cambiarlo: Host → **Ajustes → Cambiar PIN**.
5. Para salir: **Bloquear** (arriba). También se bloquea solo al cambiar de pantalla o tras **5 minutos** sin tocar.

> **Ojo.** **No hay forma de recuperar un PIN olvidado** (se guarda cifrado). Apúntalo. Si se pierde, la única salida es borrar los datos de la web en el móvil, que borra la partida: haz antes **Exportar partida**.

### Eventos sorpresa (porción “Evento”)

- **Lluvia de oro**: Los dos recibís +20 monedas.
- **Viento a favor**: Quien va perdiendo en puntos recibe +15 puntos.
- **Happy Hour**: La próxima prueba da doble recompensa a los dos.

## 9. Cómo entregar premios

1. Los premios con efecto (monedas, puntos, cartas, llaves, cajas) se cobran **solos** al abrir.
2. Los premios físicos o vales se entregan en persona. Después: **Más → Inventario** → elegir jugador → **Canjear**.
3. Para ver todo lo entregado: Host → **Premios → Premios entregados**.
4. Premios fuera de la app: Host → Control → **Ajustar marcador** con motivo, o **Dar carta / Dar caja / Dar Llave Legendaria**.

> **La Butaca de Oro** (Silver Box) gana una subasta de la Movie Lottery sin pujar: en Noche de cine → Subasta aparece el botón **Butaca de Oro** junto a **Subastar** mientras no esté canjeada.

<a id="fallos"></a>

## 11. Qué hacer si algo falla

| Problema | Solución |
|---|---|
| La app no abre sin conexión | Ábrela una vez con WiFi desde el icono y espera unos 10 s. Prueba antes en modo avión. |
| Se registró mal un resultado | Host → Control → **Ajustar marcador** con el motivo (resta o suma). |
| Un sobre no se abre cuando debía | Host → **Sobres → Desbloquear ahora**. |
| Falta una caja o una llave | Host → Control → **Dar caja** / **Dar Llave Legendaria**. |
| Se cierra o se cuelga la app | Vuelve a abrirla: todo está guardado al instante. |
| Cambio de móvil o se borra la partida | Host → Ajustes → **Importar**, pegando el contenido del archivo `homelottery-partida.json` exportado. |
| Hay que empezar de cero | Host → Ajustes → **Reinicio seguro**: escribir REINICIAR → **Reiniciar partida** (puedes conservar PIN y textos). |
| Tatiana ha visto Host | Se bloquea solo al salir y a los 5 minutos. Pulsa **Bloquear** siempre. |
| Hay que repetir la Invitación | Host → Ajustes → **Volver a mostrar**. |

### Plan B del día

- **ARK no termina de actualizar**: No pasa nada: en el EP 04 jugad Split Fiction (Silencio Total + Objetivo Oculto) y Rocket League al mejor de 3. Las pruebas de ARK quedan para otro día.
- **Un juego no funciona / no hay internet**: Cartas y dados entero funciona sin conexión: Escoba, Dados Mentirosos, Hold'em de salón. O Brawlhalla en local.
- **No tenemos algún material**: Cada prueba lista sus materiales: elige otra de la misma categoría con "Pasar / cambiar" → "Sustituir al azar". Sin dados: usa la app (Cartas y dados → Dados). Sin baraja: Carta al azar en Cartas y dados.
- **Nos cansamos de una categoría**: Salta de episodio en The Show (toca el episodio → "Saltar a este episodio") o usa "Prueba al azar" en Challenges filtrando por otra categoría.
- **Queremos cambiar el horario**: El horario es solo orientativo. Los episodios se avanzan a mano: si vais tarde, juega 2 pruebas por episodio en lugar de 4.
- **No queremos seguir una prueba**: "Pasar / cambiar" en la prueba: no penaliza nunca. Si es romántica o picante, se pasa sin explicaciones.
- **Alguien va muy por detrás**: El juego ya ayuda (bonus remontada, Sobre de la Remontada). Si hace falta más: Host → Control → regala una caja o carta, o lanza un Evento con la ruleta.
- **Se cierra la app o se apaga el móvil**: Todo se guarda automáticamente en el navegador del móvil. Al volver a abrir, la partida sigue donde estaba. Para más seguridad: Host → Ajustes → Exportar partida.
- **Tatiana quiere usar su propio móvil**: Los datos viven en cada dispositivo: el progreso NO se sincroniza entre móviles. Usad un solo móvil como "consola" del concurso (modo pantalla compartida, ya activado).

> **Truco.** Copia de seguridad recomendada: Host → Ajustes → **Exportar partida** después de cada episodio. Importar pide **pegar el texto** del archivo (no hay selector de archivos).

Las probabilidades son las base: la app quita en directo los únicos ya entregados, los picantes si no lo habéis activado los dos y los personales que no son de quien abre. ### El desayuno

1. **Preparación (15-20 min).** Café o zumo primero. Tostadas al final para que lleguen calientes. Huevos fritos a fuego medio con aceite caliente; sal al servir.
2. **Presentación.** Bandeja: huevos, tostadas, zumo, café, fruta cortada. Una servilleta doblada y, si puedes, una flor o una nota con "Episodio 01".
3. **Prepara la cata a ciegas.** Deja aparte 3 bocados para la Operación Desayuno: un trozo de fruta, una tostada con algo (mermelada, miel) y un bocado sorpresa (chocolate, queso, frutos secos).
4. **El móvil.** Abre HOMELOTTERY: debe estar en la pantalla "Buenos días, Tatiana". Brillo alto, volumen medio, sin notificaciones (modo No molestar).
5. **La entrega.** Entra con la bandeja, déjala, y dale el móvil sin decir nada. Solo: "Esto es para ti". Deja que lea sola la invitación (dura ~8 segundos en aparecer completa).
6. **Iniciar el Episodio 01.** Ella pulsa DESCUBRIR MI SORPRESA → Reglas → abre el Primer Sobre → configura sus límites → EMPEZAR LA MISIÓN. Tú haces de presentador de la Operación Desayuno y registras el resultado.
